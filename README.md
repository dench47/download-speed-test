# Замер скорости скачивания

Консольный скрипт на Python без внешних зависимостей: делает 10 последовательных
запросов к одному адресу, дожидается полного ответа на каждый, считает среднее
время запроса, общий объём скачанных данных и печатает скорость скачивания.

## Запуск

Нужен Python 3.10+, ничего устанавливать не требуется.

```
python speedtest.py <адрес>
```

Пример с тяжёлым файлом на 10 МБ:

```
python speedtest.py https://speedtest.selectel.ru/10MB
```

Число запросов можно поменять (по умолчанию 10):

```
python speedtest.py https://speedtest.selectel.ru/10MB -n 5
```

## Единицы измерения

Скорость выводится в двух единицах: **Мбит/с** и **МБ/с**.

- 1 байт = 8 бит, поэтому мегабиты в секунду в 8 раз больше мегабайт в секунду
- 1 МБ = 1024 КБ = 1024 * 1024 байт

## Пример вывода

```
[ 1/3] 10.0 МБ за 1.31 c -> 64.0 Мбит/с
[ 2/3] 10.0 МБ за 1.31 c -> 63.9 Мбит/с
[ 3/3] 10.0 МБ за 1.32 c -> 63.7 Мбит/с

Адрес: https://speedtest.selectel.ru/10MB, запросов: 3
Среднее время запроса: 1.31 c
Общий объём: 30.0 МБ за 3.94 c
Скорость скачивания: 63.8 Мбит/с (7.61 МБ/с)
```

(пример с флагом `-n 3`; при запуске без флага будет 10 запросов)

## Как это работает

- `urllib.request.urlopen` открывает соединение, `resp.read()` читает тело ответа
  до конца: это гарантирует, что запрос завершён полностью, а не началом потока
- время каждого запроса меряется `time.perf_counter()` вокруг открытия и чтения
- запросы идут строго последовательно: следующий начинается после полного завершения предыдущего
- скорость = общий объём в битах / общее время; среднее время = сумма времён / число запросов
